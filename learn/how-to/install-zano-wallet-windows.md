**Short answer:** Download the Zano Wallet installer from the tagged release, run it, and let the first sync finish before you create or restore a wallet.

## You'll see this if

- You are setting up Zano Wallet on a new Windows PC
- The installer will not start, or Windows shows a blue warning screen

## Why it happens

Windows treats any new desktop installer with caution, and the first launch of Zano Wallet also downloads the blockchain, so setup feels slower than a normal app.

## How to fix it

1. Download `zano-wallet-2.0.4-installer.exe` from the release page.
2. Compare its SHA-256 with the table on the release page.
3. Double-click the installer and accept the default folder unless your system drive is nearly full.
4. Start Zano Wallet and wait for the sync bar to reach 100%.
5. Create a new wallet or restore one from your seed phrase.

Related reading: [Windows Defender Flags the Zano Wallet Installer: What to Do](./windows-defender-false-positive-zano-wallet.md) and the [Zano Wallet download page](https://github.com/zano-projects/Zano-Wallet/tree/master/learn).

## If that didn't work

If the installer closes instantly, right-click it and choose Run as administrator, then try again after a restart. You can also read [Zano Wallet Sync Stuck at 0% or Not Moving](./zano-wallet-sync-stuck.md).

## Prevent it next time

Keep 30 GB or more free on the drive that holds the blockchain, and always install updates from the same release page. More guides: [Zano Wallet FAQ](https://github.com/zano-projects/Zano-Wallet/tree/master/learn).

## FAQ

**Is Zano Wallet free on Windows?**  
Yes. The installer costs nothing; you only pay normal network fees when you send coins.

**Does it work on Windows 10?**  
Yes, both Windows 10 and Windows 11 (64-bit) are supported.
