**Short answer:** Update to the latest Zano Wallet and repeat setup; write the words by hand rather than copying them.

## You'll see this if

- The seed screen is blank
- Copy does nothing on Windows

## Why it happens

Older builds and some clipboard tools interfere with the seed screen. Copying is also discouraged because clipboards can be read by other apps.

## How to fix it

1. Close the wallet.
2. Install the latest release.
3. Start setup again and wait for the seed to appear.
4. Write each word on paper in order.
5. Confirm the seed in the next step.

Related reading: [Create a New Zano Wallet Step by Step](./create-new-zano-wallet.md) and the [Zano Wallet FAQ](https://github.com/zano-projects/Zano-Wallet/tree/master/learn).

## If that didn't work

If it is still blank, try running as administrator on Windows or a fresh user profile. You can also read [How to Back Up Zano Wallet Properly](./backup-zano-wallet.md).

## Prevent it next time

Do not keep seeds in clipboard managers, notes apps or cloud documents. More guides: [security practices](https://github.com/zano-projects/Zano-Wallet/tree/master/learn).

> [!WARNING]
> Nobody from Zano Wallet will ever ask for your seed phrase. Never type it into a website or chat.

## FAQ

**Is copying the seed unsafe?**  
It is riskier than paper because other software can read the clipboard.

**Can I see my seed again later?**  
Back it up at setup; treat that moment as the main chance.
