**Short answer:** Your coins are safe if you still have the seed phrase; restore from it in the latest Zano Wallet.

## You'll see this if

- Your computer died
- You reinstalled your OS and forgot to copy the wallet file

## Why it happens

The .wallet file is an encrypted local copy of your keys. The seed phrase can rebuild it anywhere.

## How to fix it

1. Find your written seed phrase.
2. Install the latest Zano Wallet on a working computer.
3. Choose restore from seed.
4. Enter the words and a new password.
5. Wait for the scan to complete.

Related reading: [Restore a Zano Wallet From Your Seed Phrase](./restore-zano-wallet-from-seed.md) and the [wallet recovery guide](https://zanowallet.io/guides/how-to-recover-zano-wallet/).

## If that didn't work

Without the seed, search old drives and backups for the .wallet file and its password; there is no other way back. You can also read [How to Back Up Zano Wallet Properly](./backup-zano-wallet.md).

## Prevent it next time

Back up both the seed on paper and the wallet file on an external drive. More on the website: [Zano Wallet security](https://zanowallet.io/security/).

> [!WARNING]
> Nobody from Zano Wallet will ever ask for your seed phrase. Never type it into a website or chat.

## FAQ

**Can support recover it for me?**  
No one can; the wallet is self-custody. Anyone offering this is a scammer.

**Is a screenshot of the seed a backup?**  
It works but is unsafe; paper is better.
