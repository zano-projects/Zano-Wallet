**Short answer:** Open the Zano Wallet .dmg, drag the app into Applications, then open it from Applications so macOS can register it properly.

## You'll see this if

- You downloaded the .dmg and are not sure what to do next
- macOS says the app cannot be opened

## Why it happens

macOS only trusts apps after they are copied to Applications and approved the first time, so opening the wallet straight from the disk image often fails.

## How to fix it

1. Download `zano-wallet-2.0.4.dmg` from the release page.
2. Double-click the .dmg and drag Zano Wallet onto the Applications folder.
3. Eject the disk image.
4. Open Applications, right-click Zano Wallet and choose Open.
5. Wait for the first sync before creating a wallet.

Related reading: [macOS Says Zano Wallet Cannot Be Opened: Fix](./macos-cannot-open-zano-wallet.md) and the [download Zano Wallet for macOS](https://zanowallet.io/download/).

## If that didn't work

If macOS still blocks it, open System Settings, Privacy and Security, and use the Open Anyway button shown for Zano Wallet. You can also read [Zano Wallet Sync Stuck at 0% or Not Moving](./zano-wallet-sync-stuck.md).

## Prevent it next time

Never run the wallet from the Downloads folder or the mounted disk image; keep the copy in Applications so updates replace it cleanly. More on the website: [desktop vs mobile wallets](https://zanowallet.io/guides/posts/desktop-vs-mobile-crypto-wallet-2026/).

## FAQ

**Does Zano Wallet run on Apple Silicon?**  
Yes, it runs on M-series Macs as well as Intel Macs on current macOS releases.

**Where are my wallet files on a Mac?**  
Wallet files are stored where you chose to save them during setup; keep a backup copy elsewhere.
