**Short answer:** Download only from the tagged release page and compare the SHA-256.

## You'll see this if

- A search ad offers Zano Wallet
- Someone sent you a download link

## Why it happens

Fake wallet sites copy branding to steal seeds.

## How to fix it

1. Use the release link in this guide.
2. Compare the SHA-256 with the release table.
3. Never enter your seed on a website.
4. Ignore download links in DMs.
5. Report suspicious sites.

Related reading: [Seed Phrase Scams Targeting Zano Users](./avoid-seed-phrase-scams.md) and the [is Zano Wallet legit](https://github.com/zano-projects/Zano-Wallet/tree/main/learn).

## If that didn't work

If you installed a fake, create a new wallet on a clean system and move funds immediately. You can also read [Windows Defender Flags the Zano Wallet Installer: What to Do](./windows-defender-false-positive-zano-wallet.md).

## Prevent it next time

Bookmark the official download page. More guides: [Zano Wallet download](https://github.com/zano-projects/Zano-Wallet/tree/main/learn).

> [!WARNING]
> Nobody from Zano Wallet will ever ask for your seed phrase. Never type it into a website or chat.

## FAQ

**Is this GitHub page legit?**  
Zano Wallet LLC works under Zano Foundation contracts; releases are published only at github.com/zano-projects.

**Do updates come by email?**  
Check the release page instead.
