**Short answer:** Confidential assets are tokens on Zano whose amounts and owners are hidden like ZANO itself.

## You'll see this if

- You heard about private stablecoins
- You want to hold tokens privately

## Why it happens

Most token chains are fully public; Zano extends its privacy to every asset.

## How to fix it

1. Install the latest Zano Wallet.
2. Add the asset you want to track.
3. Receive it to your normal address.
4. Send it like ZANO.
5. Amounts stay hidden on-chain.

Related reading: [How Zano Keeps Transactions Private](./zano-privacy-how-it-works.md) and the [confidential assets feature](https://zanowallet.io/features/confidential-assets/).

## If that didn't work

If an asset does not show, add it by its asset ID in the wallet. You can also read [Atomic Swaps With Zano](./zano-atomic-swaps.md).

## Prevent it next time

Only add assets from sources you trust; anyone can issue tokens. More on the website: [why privacy coins matter](https://zanowallet.io/guides/posts/why-privacy-coins-matter-2026/).

## FAQ

**Do assets need separate wallets?**  
No, Zano Wallet holds them together.

**Are fees paid in ZANO?**  
Yes.
