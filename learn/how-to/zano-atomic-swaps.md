**Short answer:** Atomic swaps let two people trade assets directly with no exchange holding funds.

## You'll see this if

- You want to trade without an exchange
- You want to swap Zano assets

## Why it happens

Swaps lock both sides so either both complete or neither does.

## How to fix it

1. Install the latest Zano Wallet.
2. Agree terms with your counterparty.
3. Create or accept the swap proposal.
4. Review the amounts.
5. Confirm; both sides settle together.

Related reading: [Zano Confidential Assets Explained](./zano-confidential-assets.md) and the [atomic swap feature](https://zanowallet.io/features/atomic-swap/).

## If that didn't work

If a swap stalls, wait for expiry; funds return to each party. You can also read [How to Buy ZANO and Move It to Your Wallet](./buy-zano-guide.md).

## Prevent it next time

Trade only amounts you have reviewed carefully. More on the website: [exchange options](https://zanowallet.io/exchange/).

## FAQ

**Is there custody risk?**  
No third party holds funds.

**Which assets?**  
Assets on the Zano chain.
