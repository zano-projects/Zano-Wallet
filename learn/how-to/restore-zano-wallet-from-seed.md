**Short answer:** Choose Restore from seed, type every word in order, set a new password, and let the wallet scan the blockchain.

## You'll see this if

- You lost your .wallet file
- You moved to a new computer

## Why it happens

The seed recreates the keys, so a lost file is not lost coins as long as you have the words.

## How to fix it

1. Install the latest Zano Wallet.
2. Choose restore from seed.
3. Type the words exactly, in order.
4. Set a new password and save the new wallet file.
5. Wait for the full scan to show your balance.

Related reading: [Zano Wallet Shows a Zero Balance](./zano-wallet-balance-zero.md) and the [how to recover a Zano wallet](https://github.com/zano-projects/Zano-Wallet/tree/main/learn).

## If that didn't work

If the balance stays at zero after a full sync, recheck each word for spelling. You can also read [Lost Your Zano .wallet File? Recover Your Coins](./lost-zano-wallet-file.md).

## Prevent it next time

Keep two offline copies of the seed in separate places. More guides: [download Zano Wallet](https://github.com/zano-projects/Zano-Wallet/tree/main/learn).

> [!WARNING]
> Nobody from Zano Wallet will ever ask for your seed phrase. Never type it into a website or chat.

## FAQ

**Do I need my old password?**  
No; you set a new one when restoring from the seed.

**Can I restore on several computers?**  
Yes, but each copy controls the same funds, so protect them all.
