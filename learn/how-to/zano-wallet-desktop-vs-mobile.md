**Short answer:** Use Zano Wallet on desktop today; the mobile app is coming soon.

## You'll see this if

- You prefer phones
- You want full features

## Why it happens

The desktop wallet runs a full node with staking.

## How to fix it

1. Install Zano Wallet on your computer.
2. Back up your seed.
3. Use it for staking and assets.
4. Watch for the mobile release.
5. Restore the same seed later on mobile.

Related reading: [How to Install Zano Wallet on Windows 10 and 11](./install-zano-wallet-windows.md) and the [desktop vs mobile wallets](https://github.com/zano-projects/Zano-Wallet/tree/main/learn).

## If that didn't work

Until then, keep the desktop wallet as your main wallet. You can also read [How to Back Up Zano Wallet Properly](./backup-zano-wallet.md).

## Prevent it next time

Keep seeds safe so you can restore on any device. More guides: [download Zano Wallet](https://github.com/zano-projects/Zano-Wallet/tree/main/learn).

## FAQ

**When is mobile released?**  
Coming soon; follow the release page.

**Will my seed work on mobile?**  
The plan is the same seed across apps.
