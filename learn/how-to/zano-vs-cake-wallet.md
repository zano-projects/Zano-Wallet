**Short answer:** Cake Wallet is a mobile multi-coin app; Zano Wallet is the desktop full-node wallet for ZANO with staking and assets.

## You'll see this if

- You use Cake Wallet on mobile
- You want native Zano features

## Why it happens

Native wallets support chain-specific features first.

## How to fix it

1. Decide desktop or mobile needs.
2. Check which Zano features matter.
3. Install Zano Wallet on desktop.
4. Back up the seed.
5. Transfer funds on-chain.

Related reading: [Zano vs Monero: Which Privacy Wallet Fits You](./zano-vs-monero.md) and the [Zano Wallet vs Cake Wallet](https://zanowallet.io/vs/cake-wallet/).

## If that didn't work

See the detailed comparison on the website. You can also read [Using Zano Wallet Without KYC](./no-kyc-zano-wallet.md).

## Prevent it next time

Keep each app's seed separate. More on the website: [is Cake Wallet safe](https://zanowallet.io/is-cake-wallet-safe/).

## FAQ

**Is a Zano Wallet mobile app coming?**  
Mobile is coming soon.

**Does Cake support staking?**  
Check Cake's own docs.
