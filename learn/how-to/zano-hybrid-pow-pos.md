**Short answer:** Zano alternates proof-of-work and proof-of-stake blocks so an attacker would need both hash power and coins.

## You'll see this if

- You want to know what secures Zano
- You are comparing Zano to Monero

## Why it happens

Mixing two security models raises the cost of attacks.

## How to fix it

1. Miners produce PoW blocks with GPUs.
2. Stakers produce PoS blocks from wallets.
3. The chain weighs both when choosing the best chain.
4. An attacker needs a majority of both.
5. Users simply see confirmed transactions.

Related reading: [How to Stake ZANO in the Desktop Wallet](./stake-zano-in-wallet.md) and the [Zano consensus](https://github.com/zano-projects/Zano-Wallet/tree/master/learn).

## If that didn't work

For deeper reading, see the consensus page linked below. You can also read [Mine Zano With Your GPU Using Progminer](./mine-zano-gpu-progminer.md).

## Prevent it next time

Taking part as a staker or miner strengthens the network. More guides: [mining Zano](https://github.com/zano-projects/Zano-Wallet/tree/master/learn).

## FAQ

**Can I both mine and stake?**  
Yes, they are independent.

**Does this affect fees?**  
Fees work normally regardless of block type.
